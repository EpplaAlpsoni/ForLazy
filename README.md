# ForLazy

A simple Linux autoclicker.

> I made this because everything else sucked.

## About

ForLazy is an autoclicker built with simplicity in mind. No unnecessary features, no complicated setup, and no messing with your system just to click repeatedly.

The goal is simple: open it, configure it, and click.

## Status

🚧 **Work in progress.**

ForLazy is currently in early development.
